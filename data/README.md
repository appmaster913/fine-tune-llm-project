# Overview of the Data Directory

This directory contains all data related to the fine-tuning of the language model. It is organized into two main subdirectories: `raw` and `processed`.

## Raw Data

The `raw` subdirectory contains the original data used for fine-tuning. This data is unprocessed and may come from various sources. It is important to maintain the integrity of this data for reproducibility and reference.

## Processed Data

The `processed` subdirectory holds the data that has been transformed and cleaned for use in the fine-tuning process. This data has undergone various preprocessing steps to ensure it is suitable for training the model.

For detailed information about the contents and structure of each subdirectory, please refer to the respective `README.md` files located in `raw` and `processed`.
