# Models Directory Overview

This directory contains the models used in the fine-tuning project. It includes both the base model and the fine-tuned model.

## Base Model

The base model serves as the starting point for fine-tuning. It is pre-trained on a large corpus and provides a solid foundation for adapting to specific tasks.

## Fine-Tuned Model

The fine-tuned model is the result of training the base model on customer data. It is optimized for performance on the specific tasks defined in this project and includes metrics and instructions for usage.
